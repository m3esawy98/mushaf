# المصحف الشريف — نسخة جاهزة للنشر على Vercel

## محتوى الفولدر
- `index.html` — التطبيق كله (الفهرس، التابات، القارئ، البحث).
- `b/` — ١٥٢ ملف لصفحات المصحف (كل ملف فيه ٤ صفحات، ٦٠٨ صفحة إجمالاً).
- `vercel.json` — إعدادات التخزين المؤقت: الصفحات بتتحفظ في المتصفح ٣٠ يوم، و`index.html` بيتحدث دايماً.

الحجم الكلي حوالي ٩٠ ميجا، أقل من حد رفع الملفات الثابتة في الخطة المجانية (100 MB).
الصفحات هنا بعرض 1050 بكسل (النسخة اللي على Claude بعرض 1441) عشان الحجم يدخل في الحد.

## الطريقة الأولى: من GitHub (الأسهل للتحديثات بعد كده)
1. اعمل repo جديد على GitHub وارفع فيه محتوى الفولدر ده (index.html و vercel.json و فولدر b).
2. ادخل vercel.com ← Add New ← Project ← اختار الـ repo.
3. في الإعدادات:
   - Framework Preset: **Other**
   - Build Command: سيبه فاضي
   - Output Directory: سيبه فاضي (الجذر)
4. دوس Deploy. هيديك رابط زي `اسم-المشروع.vercel.app`.

## الطريقة التانية: من سطر الأوامر
محتاج Node.js على جهازك. من جوه الفولدر:
```
npx vercel          # أول مرة: هيطلب تسجيل الدخول ويسألك كام سؤال، وافق على الافتراضي
npx vercel --prod   # النشر النهائي
```

## بعد النشر
- لو عايز دومين خاص: من إعدادات المشروع على Vercel ← Domains.
- الخطة المجانية (Hobby) لاستخدام شخصي وغير تجاري.

## تطبيق على الموبايل وقراءة بدون إنترنت (PWA)
الملفات `manifest.webmanifest` و `sw.js` والأيقونات بتخلي الموقع يشتغل كتطبيق:
- **أندرويد (كروم):** هيظهر زرار «ثبّت التطبيق على الجهاز» في أول الصفحة، أو من قائمة كروم ← «تثبيت التطبيق».
- **آيفون (Safari):** زرار المشاركة ← «إضافة إلى الشاشة الرئيسية».
- **القراءة بدون نت:** زرار «احفظ المصحف للقراءة بدون إنترنت» بيحمّل الـ ٦٠٨ صفحة مرة واحدة (حوالي ٩٠ ميجا). أي صفحة بتفتحها بتتحفظ لوحدها كمان.
- لو غيرت صور الصفحات بعد كده، غيّر `mushaf-pages-v1` لـ `v2` في `sw.js` وفي `index.html` عشان الأجهزة تحمّل الجديد.

## دومين خاص
1. اشتري دومين من أي شركة (Namecheap، GoDaddy، Cloudflare…) أو من Vercel نفسه.
2. في مشروعك على Vercel: Settings ← Domains ← اكتب الدومين ← Add.
3. Vercel هيقولك تضيف سجل DNS (غالباً A record أو CNAME) في لوحة شركة الدومين. ضيفه واستنى دقايق لحد ما يتفعّل، والـ HTTPS بيتعمل لوحده.
